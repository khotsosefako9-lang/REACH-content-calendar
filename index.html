05 Events and platforms

Events borrow a day. Platforms share the content.

Event content takes the nearest pillar's slot instead of adding a posting day: a countdown carousel or behind-the-planning clip beforehand, a poster for the announcement, a recap the week after. Instagram and Facebook then run the same posts, tuned to how each is used.

Instagram

  • Feed carries the polished version, Stories reshare it plus extra behind-the-scenes clips
  • First line of the caption needs to hold attention before "more" gets tapped

Facebook

  • Same visuals, longer captions, an audience that reads and shares more
  • Events feature used for anything with a date, recap videos uploaded natively too
